# 📱 Mobile Sales Dashboard using Power BI

An interactive Power BI dashboard developed to analyze mobile sales across brands, cities, payment methods, and customer ratings. The dashboard provides actionable insights through dynamic visualizations and KPIs to support data-driven decision-making.

## 🚀 Tech Stack
- Power BI
- SQL
- Excel
- DAX
- Power Query

## 📊 Key Features
- Interactive dashboard with slicers and filters
- Sales analysis by brand, city, and payment method
- KPI cards for Total Sales, Transactions, Quantity, and Average Sales
- DAX measures for advanced calculations
- Data cleaning and transformation using Power Query
